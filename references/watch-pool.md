# 关注池指南

关注池是使用者自己维护的“我要持续跟踪什么”的清单：企业、项目、园区、专题和政策。它让每期简报回答两个问题：**我关心的对象这期有什么已核实的公开动态？重点对象有没有动静？**

## 1. 关注池不是客户名单

银行员工最容易踩的坑，是把行内客户名单原样当成关注池。必须守住：

- 只放可以公开研究的对象。条目进入关注池前，用户须确认 `public_ok=true`。
- 不记录授信、额度、余额、存款、账户、联系人、电话、“我行/本行客户”“存量客户”等信息；工具会拒绝这类备注、标签和岗位描述。
- 用户说“这是我们的客户名单”时，不提交外部检索，不复述名单中的敏感字段，请用户改给公开研究范围（例如“赣州稀土产业链上市公司”）。
- 报告只展示条目名称、类型和优先级；标签、备注不进报告。分享长图前提醒用户确认这些名称可以对外展示。

## 2. 建立关注池

**对话添加**：用户说“把江西铜业、赣锋锂业和南昌高新区加到关注池，赣锋设为重点”。智能体核实全称与公开身份（交易所公告、企业官网或公开登记信息），生成：

```json
[{"id": "jxcopper", "name": "江西铜业股份有限公司", "type": "enterprise", "aliases": ["江西铜业"], "public_ok": true},
 {"id": "ganfeng", "name": "江西赣锋锂业集团股份有限公司", "type": "enterprise", "aliases": ["赣锋锂业"], "priority": "high", "public_ok": true},
 {"id": "nc-hitech", "name": "南昌高新技术产业开发区", "type": "park", "aliases": ["南昌高新区"], "public_ok": true}]
```

简称有多个候选时给出候选请用户选，不凭记忆替用户选法人。

**Excel批量导入**：

1. `pool-template --out 关注池模板.csv` 生成模板，用户用Excel填写后“另存为 → CSV UTF-8”。
2. `pool-import --csv 关注池.csv --out 关注池.json` 转换。表头可用中文（编号、名称、类型、别名、统一社会信用代码、地区、标签、优先级、备注）或英文；名称、类型必填；多值用分号分隔；优先级填高/中/低；编号留空时自动生成 `pool-001` 等。
3. 出错时提示CSV行号，例如“CSV第3行 $.watch_pool[1].note: 关注池不得记录授信……”，改表后重导。
4. 把结果合并进配置的 `watch_pool` 前给用户看一遍，再按用户要求保存。

## 3. 优先级怎么用

| 优先级 | 采集 | 报告 |
|---|---|---|
| high | 每期按名称、别名、证券代码单独检索公告、环评、招采、政府公示 | 命中时排在关注池动态前列；无动态时列入“高优先级条目本期未见已核实公开动态” |
| normal | 随覆盖矩阵检索，命中即记录 | 命中时列出 |
| low | 只在覆盖矩阵中顺带识别 | 命中时列出 |

“未见已核实公开动态”只说明本期检索没有发现合格事项，不推断经营变化，也不等于没有事件发生。

## 4. 命中与记录

- 命中以主体或对象核验一致为准：同名不同法人、简称撞名、母子公司都不能自动归并；`include_subsidiaries=true` 时才纳入逐家核验的子公司。
- 一个事项可命中多个条目（如企业与其所在园区），在 `pool_ids` 全部列出。
- 在 `02-selected.json` 记录命中依据（名称、代码或原文段落）。
- 最终报告写入 `pool` 快照（id、名称、类型、优先级）和事项的 `pool_ids`，渲染器据此生成“关注池动态”面板与事项上的“关注池 · 名称”标记。

## 5. 维护

- 每月请用户检查一次：已完成的项目、已整合的企业可以移出或降为low。
- 企业更名、合并时更新name并把旧名放入aliases，保留id不变，便于跨期对比。
- 关注池超过300项时建议拆成多份配置（如按设区市或条线），而不是降低检索质量。
