# 写作规范：标题、正文、速览与口径

简报的读者要在几十秒内知道“谁、做了什么、到了哪一步、接下来看什么”。以下规则让不同地区、不同期次的稿件读起来一致。`briefing_tool.py lint` 会自动检查其中可机器判断的部分。

## 1. 标题

格式：**主体 + 动作 + 对象 + 状态**，一般不超过30字，最多40字。

| 不好 | 好 | 原因 |
|---|---|---|
| 重磅！百亿项目落地甲市 | 甲市与乙某新材料签约年产2万吨正极材料项目 | 去掉渲染词；“落地”含义不清，签约≠落地 |
| 甲市新能源产业再迎利好 | 甲市印发支持新型储能发展若干措施 | 写清具体文件，不用带交易含义的“利好” |
| 关于乙某公司的情况 | 乙某新材料正极材料项目环评进入拟批准公示 | 写清阶段 |
| 丙市低空经济产业园开工建设 | 丙市低空经济产业园一期取得施工许可 | 只有施工许可时不写“开工” |

标题不用感叹号和问号，不用引号制造修辞效果；企业在标题中可用公认简称，正文首次出现给全称。

## 2. 事实正文（reader_summary）

2–4句，80–200字为宜：

1. 第一句：谁、何时、发布了什么、事项处于哪个阶段。
2. 第二句：关键数字，紧跟口径（计划总投资、备案总投资、中标金额、募资净额等）。
3. 第三句（如需要）：限制或尚未发生的事——“尚需股东大会审议”“拟批准不等于审批决定已公开”“投用时间为计划”。

不写入读者正文的内容：日期编码说明（“00:00为占位”）、抓取过程、证据根、渠道检索细节。这些写在 `summary`、`analysis` 和运行记录里。

**示例**

> 乙市生态环境局公示乙某新材料有限公司年产2万吨电池正极材料项目环评拟批准意见，公示期5个工作日。拟批准不等于审批决定已公开。

## 3. 研究关注（reader_analysis）

1–2句，写**下一步可公开核实的节点**或**理解这条事实需要注意的口径**，用条件句，不下结论。

| 不好 | 好 |
|---|---|
| 该企业融资需求旺盛，可重点营销 | 关注股东大会表决结果及募投项目备案文件 |
| 项目必将带动千亿产业集群 | 清单为计划口径，可跟踪单体项目的施工许可与用地公告 |
| 建议增持该公司股票 | 募资上限与项目投资为不同口径，不相加 |

不推断贷款需求、授信额度、营销切入点，不给买卖建议、目标价或收益判断，不对未披露的经营数据下判断。

## 4. 一句话速览（summary）

60–140字，挑本期最重要的2–3个实际变化，按“主体+变化+状态”写，分号连接；引用对应事项ID。

| 不好 | 原因 |
|---|---|
| 本期共收录12条，其中政府8条、企业4条。 | 用条数充当摘要 |
| 一、政府资讯；二、企业资讯；三、专题分析。 | 复制目录 |
| 本周区域经济运行稳中向好，产业发展势头强劲。 | 空话，无主体无事实 |

> 甲市公布第四季度56个集中开工项目清单；乙某新材料正极材料项目进入环评拟批准公示，其母公司同期完成9.6亿元定增；示例省启动制造业数字化转型专项资金申报。

## 5. 数字与口径

- 金额用阿拉伯数字加单位：“35亿元”“1,280万元”“约18万平方米”；同一篇统一单位。
- 每个金额紧跟口径：计划总投资 / 备案总投资 / 签约额 / 中标金额 / 合同金额 / 预算金额 / 募资上限 / 募资净额 / 实际到位。不同口径**不相加**、不比较，也不推算差额。
- 增速写清比较基期（同比、环比、较上年末）和统计期。
- 计划、目标、预计写明“计划”“预计”；`event_date` 只填已发生的日期，计划里程碑写进正文。
- `key_figures` 每个数字只放一个口径，`note` 写口径，`value` 保留原文数字精度，不四舍五入成更“好看”的数。

## 6. 阶段词表（stage）

按原文选词，不升级、不合并：

| 类别 | 阶段（由早到晚，仅作参考，不代表必经流程） |
|---|---|
| 项目 | 签约 → 项目备案/核准 → 环评受理 → 环评拟批准公示 → 环评审批决定 → 用地出让成交 → 施工许可 → 开工 → 主体封顶 → 竣工 → 投产/投用 |
| 招采 | 采购意向 → 招标公告 → 中标候选人公示 → 中标结果 → 合同公告；或废标/终止 |
| 政策 | 征求意见 → 印发 → 施行 → 解读/配套细则 → 申报启动 → 名单公示 → 正式认定 |
| 企业公告 | 预案/董事会审议通过 → 股东大会审议通过 → 监管受理/审核/注册 → 发行完成/交易完成 |

“拟受理、拟批准、审批决定公开、采购启动、废标、备案、投产”分别表述。不同项目的阶段在图表中只做计数，不连成漏斗。

## 7. 主题词表（theme）

每条只填一个主theme，尽量从下表选，跨期保持一致，便于周月对比；确需新词时保持4–8字的名词短语。

| 主题 | 典型内容 |
|---|---|
| 先进制造 | 装备、汽车及零部件、智能制造基地 |
| 制造业数智化 | 数字化转型、工业互联网、智能工厂 |
| 新能源与储能 | 光伏、风电、锂电材料、新型储能、氢能 |
| 新材料 | 化工新材料、有色金属深加工、稀土功能材料 |
| 电子信息 | 集成电路、显示、电子元器件 |
| 数字经济 | 算力、数据要素、软件与信息服务、智慧城市 |
| 生物医药 | 创新药、医疗器械、中医药 |
| 低空经济 | 无人机、通用航空、低空基础设施 |
| 绿色低碳 | 节能降碳技改、环保、循环经济 |
| 基础设施与重大项目 | 交通、水利、能源基础设施、重大项目清单 |
| 现代农业与食品 | 农业产业化、食品加工、冷链 |
| 文旅消费 | 文旅项目、商贸、消费政策 |
| 科技创新 | 创新平台、科技计划、成果转化 |
| 产业金融与资本市场 | 产业基金、上市、发债、定增、并购 |
| 营商环境与改革 | 审批改革、国企改革、要素市场化 |
| 开放与外贸 | 自贸试验区、外资、跨境电商、口岸 |

审批手续本身（环评、备案）是stage，不是theme。

## 8. 禁用与慎用措辞

| 类别 | 例词 | lint级别 |
|---|---|---|
| 渲染与交易含义 | 重磅、炸裂、震撼、史上最、全面爆发、王炸、必将、利好、利空（“盈利好转”“让利空间”等不算） | warning（全部字段） |
| 推断信贷与营销 | 可授信、建议授信、额度建议、营销机会、营销切入、客户经理可、建议客户经理；建议…拜访、授信/营销潜力、重点营销对象 | error（全部字段） |
| 分析中的推断 | 拜访客户、上门拜访、贷款需求、融资/资金需求旺盛（较大、较强）、可（重点）营销、业务切入点 | error（仅研究关注、专题、后续关注等分析文字；领导走访企业等事实报道不受限） |
| 信贷事实词 | 授信额度、放款：原文已披露时可在事实正文中照录口径（如银政签约“意向授信额度”） | warning（仅研究关注、专题、后续关注等分析文字） |
| 投资建议 | 建议买入/增持/卖出/减持、推荐买入、目标价（“目标价格保险/补贴”除外）、买入/增持/推荐等评级、投资评级、逢低布局、逢高减持、择机建仓、建议/可/适当加仓、股价有望、值得投资、稳赚（同句含警惕、提示、诈骗、宣判等词的风险提示除外）；分析文字中的“收益承诺”“继续加仓” | error |
| 编制过程说明（读者正文中） | 编码占位、占位符、证据根、抓取/检索时间（日期、时点）、采集时间、列表页日期、爬取 | error（标题、分区名、速览、读者正文、专题、关键数字、后续关注）；未编reader_analysis时，analysis中的这类说明报warning |

政策名称中的数量（“12条措施”“若干措施”）和专业术语（“颠覆性技术”“智能抓取”“信息采集时间”）不受这些规则限制；来源名称照录原题，命中推断或建议措辞只报warning；`lint` 只匹配“本期收录N条”“政府资讯N条”这类自指计数。

## 9. 发布前自查

- [ ] 速览讲了具体主体、变化和状态，没有条数
- [ ] 每条标题能看出阶段；“开工”“投产”有对应原文
- [ ] 金额都有口径，没有不同口径相加
- [ ] 研究关注是可核实的下一步，不是营销或投资建议
- [ ] 每条都有theme、stage、publisher_type
- [ ] `lint` 无error，warning已处理或说明
