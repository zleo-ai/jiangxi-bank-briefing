# 配置规范 v1（江西银行业版）

## 首次使用

用自然语言完成配置，无需手写JSON。最少只需要岗位视角，其余都有默认值：

```text
默认覆盖江西省全省、分行综合视角，可直接生成。
可选补充：① 设区市或县区；② 你的岗位（或用自己的话描述岗位）；③ 想重点看的方向；
④ 关注池：重点企业、项目、园区、专题、政策（可提供Excel名单）；⑤ 只看政府或只看企业；⑥ 版式。
```

先读取用户已给出的信息，不重复询问，不导入任何已有内部名单。会话内可临时使用；只有用户要求保存时才写入用户工作目录的 `briefing-config.json`，并先备份旧版。

## 字段

| 字段 | 必填 | 规则与默认行为 |
|---|---|---|
| schema_version | 是 | 整数1 |
| audience | 是 | 岗位视角键，见[岗位视角目录](periodic-analysis.md#岗位视角目录)；默认 `regional`（分行综合）。`custom` 表示自定义岗位，此时必须填写 `role_profile.title` |
| regions | 否 | 默认 `[{"name":"江西省","parent":"中国","level":"province"}]`。最多30项，每项 name、parent、level 必填：province只能是江西省；city必须是11个设区市之一且parent为江西省；county的parent必须是11个设区市之一 |
| role_profile | 否 | 岗位画像对象，见下节 |
| watch_pool | 否 | 关注池数组，最多300项，见下节与[关注池指南](watch-pool.md) |
| topics | 否 | 筛选用主题，最多30项；与 `require_topic_match` 配合实现“只看选定主题” |
| scope_mode | 否 | any（默认）或all，见真值表 |
| source_types | 否 | 默认[gov, enterprise, other]，按原始披露主体过滤 |
| require_topic_match | 否 | 默认false；true时topics必须非空 |
| history_mode | 否 | aggregate_only（默认）或 backfill_public，含义同父技能 |
| timezone | 否 | 只支持Asia/Shanghai |
| max_items | 否 | 1–50，默认12，只限制展示卡片 |
| config_name | 否 | 1–80字，本地识别用，不形成单位抬头 |
| presentation | 否 | theme / layout / color_scheme / charts；默认标准版+商务蓝 |

11个设区市：南昌市、景德镇市、萍乡市、九江市、新余市、鹰潭市、赣州市、吉安市、宜春市、抚州市、上饶市。县区名称由执行智能体按官方区划核验（区划调整时注明时期）。

所有字符串去首尾空白后不得为空；拒绝控制字符、零宽和双向覆盖等不可见字符、重复键、未声明字段、NaN；文件≤256KB。

## 岗位画像 role_profile

| 字段 | 规则 | 用途 |
|---|---|---|
| title | 1–40字；audience为custom时必填 | 岗位名称，只出现在折叠的运行记录，不作报头 |
| focus_directions | 最多12项，每项≤40字，不重复 | 研究方向：编辑排序、速览取舍，并显示在报头“关注方向” |
| key_questions | 最多10项，每项≤120字 | 希望简报回答的问题；研究关注优先回答其中能用公开信息回答的部分 |
| deprioritize | 最多10项，每项≤40字 | 少看的内容：排序靠后、少展开，但不因此删除合格事实 |

岗位画像不是筛选条件，不改变证据门和地域范围。任何字段不得含授信、额度、余额、存款、账户、联系人、电话、“我行/本行客户”等内部信息，工具会拒绝。

示例：用户说“我做园区金融服务，主要看开发区政策、园区企业投产和标准厂房，消费类新闻少看” →

```json
{"audience": "custom",
 "role_profile": {"title": "园区金融服务专员",
                  "focus_directions": ["开发区与产业园区政策", "园区内企业投产与技改", "标准厂房与基础设施"],
                  "deprioritize": ["个人消费类新闻"]}}
```

## 关注池 watch_pool

| 字段 | 必填 | 规则 |
|---|---|---|
| id | 是 | 小写字母、数字、-、_，1–40位，池内唯一；报告用它引用 |
| name | 是 | 经核验的全称（企业）或规范名称（项目、园区、政策），≤100字 |
| type | 是 | enterprise企业 / project项目 / park园区 / topic专题 / policy政策 |
| public_ok | 是 | 必须为true：用户确认该条目可作为公开研究范围检索 |
| aliases | 否 | 最多20个别名；与其他条目名称或别名不得重复 |
| identifier | 否 | 仅企业：统一社会信用代码或证券代码 |
| region | 否 | 江西省、设区市，或“设区市+县区”（如“赣州市南康区”）；辅助消歧，不等于事件发生地 |
| tags | 否 | 最多10个，每个≤20字，用于自己分组 |
| priority | 否 | high / normal（默认）/ low；高优先级条目每期单独检索，无动态时在报告中列出 |
| note | 否 | ≤200字，只记录研究备注，不进报告 |
| include_subsidiaries | 否 | 仅企业；true时只纳入逐家核验控制关系的子公司 |

备注和标签不得含授信、额度、余额、存款、账户、联系人、电话、“我行/本行客户”“存量客户”等内部信息，工具会拒绝。

## 范围真值表

R=命中任一地区，P=命中任一关注池条目，T=命中任一topics。

| 关注池 | topics | any | all |
|---|---|---|---|
| 空 | 空 | R | R |
| 非空 | 空 | R或P | R且P |
| 空 | 非空 | R或T | R且T |
| 非空 | 非空 | R或P或T | R且P且T |

any会收录关注池企业在江西以外的事项（如江西企业的省外投资），首屏注明“地区/关注池/主题任一命中”，域外事项单列；只想看江西境内的关注池动态选all。最终入选还需命中 `source_types`，且 `require_topic_match=true` 时必须T命中。

地区命中：政策明确适用、事件或项目实际在所选地区，或企业注册地在所选地区且确属该主体事项。省级选择覆盖全部下辖区域；全国政策明确普遍适用时标“上位政策”。关注池命中：主体或对象经核验一致；同名、简称、母子公司不得自动归并。

## 修改与保存

“本次只看九江”临时替换regions；“以后增加上饶”追加；“改成上饶”替换。“把某公司移出关注池”删除该条目及别名；“把某园区设为重点”改priority。持久化前备份 `briefing-config.backup-时间标识.json`，校验通过后写入；失败则保持旧版并如实说明。多份配置并存时请用户指定。

## 示例

| 文件 | 内容 |
|---|---|
| `examples/config-minimal.json` | 只有岗位视角，其余默认（江西全省） |
| `examples/config-corporate-ganzhou.json` | 公司金融：赣州+南昌，岗位画像，关注池含企业、政策、园区 |
| `examples/config-custom-role.json` | 自定义岗位“园区金融服务专员”，速读版 |
| `examples/config-risk.json` | 风险管理：只看政府与企业原始披露，要报版素墨 |
| `examples/pool-template.csv` | Excel可编辑的关注池模板 |

示例中的企业均为公开上市公司或公开园区，用于演示格式，不代表任何机构的客户关系。
