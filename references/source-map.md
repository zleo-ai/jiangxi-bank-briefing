# 江西信源地图

下表列出江西省内常用的一手发布渠道类型与机构名称，以及银行岗位常用的检索式。**这不是域名白名单**：除标注的少数入口外，执行时用“机构全称+官网”找到站点，实际打开页面核实域名归属、机构主体、发布日期和正文后再引用。机构改革、栏目改版时以当时官网为准。

## 1. 省级渠道

| 渠道 | 机构 | 重点栏目 | 银行岗位常用 |
|---|---|---|---|
| 政府门户 | 江西省人民政府（www.jiangxi.gov.cn） | 政府信息公开、政策文件、政策解读 | 全部 |

| 工业和信息化 | 江西省工业和信息化厅（gxt.jiangxi.gov.cn） | 通知公告、产业链、专精特新、数字化转型 | 科技金融、普惠、公司金融 |
| 商务 | 江西省商务厅 | 招商引资、外资外贸、开放平台 | 跨境金融、交易银行 |
| 科技 | 江西省科学技术厅 | 科技计划、创新平台、高新技术企业公示 | 科技金融 |

| 金融监管 | 中国人民银行江西省分行；国家金融监督管理总局江西监管局；中国证券监督管理委员会江西监管局 | 政策发布、行政处罚 | 风险、内控合规、金融机构 |

## 2. 设区市、县区与开发区

11个设区市（南昌、景德镇、萍乡、九江、新余、鹰潭、赣州、吉安、宜春、抚州、上饶）各有“XX市人民政府”门户，以及对应的发改委、工信局、商务局、生态环境局、自然资源局和公共资源交易中心。县区公开程度差异大，查不到官方站点时记“渠道不可用”，不用转载网站代替。

国家级与省级开发区、新区的管委会站点常发布入驻、投产、技改和标准厂房信息，例如赣江新区、南昌高新技术产业开发区、南昌经济技术开发区、赣州经济技术开发区、九江经济技术开发区等。园区不是行政区，按所在县区配置地区，园区本身可放入关注池（type=park）。

## 3. 国家级入口（跨地区通用）

中国政府网（www.gov.cn）政策文件库；全国投资项目在线审批监管平台（备案与核准公示）；国家企业信用信息公示系统（www.gsxt.gov.cn）；巨潮资讯网（www.cninfo.com.cn）、上海证券交易所（www.sse.com.cn）、深圳证券交易所（www.szse.cn）、北京证券交易所（www.bse.cn）；全国中小企业股份转让系统（www.neeq.com.cn）；中国货币网（www.chinamoney.com.cn）与上海清算所（www.shclearing.com.cn）的债券发行文件；中国政府采购网（www.ccgp.gov.cn）；中国裁判文书网与中国执行信息公开网（只用于法人主体必要事实）。

## 4. 江西常见产业与政策主题（检索提示）

以下只用于扩展检索词，具体提法、范围和数字以当期官方文件为准：

- 制造业重点产业链（江西省“1269”行动计划相关文件）、有色金属、电子信息、新能源、装备制造、航空、中医药、虚拟现实；
- 地市特色：赣州稀土与有色、宜春与新余锂电、上饶光伏、景德镇陶瓷与航空、鹰潭铜产业、南昌电子信息与VR、九江沿江产业与石化、吉安电子信息、萍乡工业陶瓷、抚州数字经济；
- 区域与开放平台：赣江新区、内陆开放型经济试验区、赣南等原中央苏区振兴发展、鄱阳湖生态经济与长江经济带。

## 5. 检索式模板

| 格 | 检索式示例 |
|---|---|
| 政策通知 | `江西省 印发 通知 {主题} {月份}`；`{设区市}人民政府 政策文件 {月份}`；`site:jiangxi.gov.cn {主题}` |
| 产业项目 | `{设区市} 重大项目 集中开工 {月份}`；`{设区市} 环评 拟批准 公示`；`{设区市} 项目 备案 {主题}`；`{设区市} 工业用地 出让 结果` |
| 招标采购 | `{设区市} 公共资源交易 {主题} 招标公告`；`{设区市} 中标候选人 公示` |
| 企业公告 | `{企业全称} 公告 {月份}`；`{证券简称} 董事会 决议`；`江西 上市公司 投资 项目 公告` |
| 公开同业 | `江西 银行 签约 {主题}`；`{设区市} 产业基金 设立`；`江西 金融 支持 {主题} 措施` |
| 关注池条目 | `{条目名称或别名} {月份}`；`{证券代码} 公告`；`{园区名称} 投产 OR 签约 OR 开工` |

检索结果只是线索；高相关候选必须打开原文核对发布日期（正文缺日期时查同机构栏目列表）。每格记录状态：已检索、已读正文、零合格、待追源或渠道失败；渠道失败影响覆盖时出观察稿。
